The office printer finally speaks: after years of paper jams, cryptic error codes and being thumped whenever it stops, it answers everyone staring at it with one line — it did not jam, it stopped on page 47 of 48 because the last page was a 12 MB screenshot of an email, and it is not the one without standards here. A single comeback, in the machine's own voice, sharp enough to stick on the machine itself.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
